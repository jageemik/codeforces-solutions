# codeforces-solutions
My C++ solutions to Codeforces problems, organized by difficulty rating.

My Codeforces handle is pythonnewb. I am currently a Newbie (973 rating) and use this repository to track my progress as I work through problems and improve my competitive programming skills :)

## Repository Structure

Solutions are organized by problem rating.

```text
codeforces-solutions/
│
├── 800/
├── 900/
├── 1000/
├── 1100/
└── ...
```

Example:

```text
800/
├── A_Difficult_Contest.cpp
├── A_Game_of_Division.cpp
└── A_Gift_Carpet.cpp
```

Each solution is named after the corresponding Codeforces problem. This repository will be updated as I solve more Codeforces problems and continue improving!!
